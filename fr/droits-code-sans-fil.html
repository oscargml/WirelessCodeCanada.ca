Vos droits du Code sur les services sans fil — expliqués

Le Code sur les services sans fil est un code de conduite obligatoire du CRTC qui s'applique à tous les contrats sans-fil des particuliers et des petites entreprises au Canada. Voici vos protections légales — ce que chacune signifie et comment l'utiliser.

Mise à jour 2025 : depuis le 30 octobre 2025, la Loi sur les télécommunications modifiée interdit tous frais pour changer de fournisseur ou résilier un service.

1. Le plafond mensuel de 50 $ sur l'excédent de données

Votre fournisseur doit suspendre les frais d'excédent de données dès qu'ils atteignent 50 $ par cycle de facturation — et ne peut vous facturer davantage sans votre accord exprès. Cela s'applique même à un forfait à l'utilisation.

2. Le plafond de 100 $ sur l'itinérance internationale

Les frais d'itinérance de données sont plafonnés à 100 $ par cycle sans votre consentement exprès. Un retour de voyage avec une facture d'itinérance à quatre chiffres non autorisée est une violation du Code.

3. Déverrouillage gratuit des appareils

Tous les téléphones doivent être vendus déverrouillés. Pour un ancien appareil verrouillé, votre fournisseur doit le déverrouiller gratuitement sur demande — sans exception ni frais.

4. Aucuns frais de résiliation après 24 mois

Sur un contrat à terme, les frais de résiliation anticipée doivent être ramenés à zéro au plus tard à 24 mois. Les facturer après deux ans n'est pas permis.

5. Aucuns frais de changement ou de résiliation (nouveau, oct. 2025)

La Loi sur les télécommunications modifiée interdit désormais tous frais pour résilier ou changer de fournisseur. Facturés après le 30 octobre 2025 ? Vous avez droit à un remboursement.

6. Aucune modification surprise du contrat

Votre fournisseur ne peut modifier les modalités clés ou le prix d'un contrat à terme sans votre consentement exprès. Les avis « mise à jour de votre forfait » qui augmentent le prix sont généralement interdits.

7. Le Résumé des renseignements essentiels

Vous avez droit à un Résumé des renseignements essentiels clair indiquant prix, durée, limites de données et modalités clés. Si votre facture ne correspond pas, vous avez une plainte solide.

8. Une période d'essai

Vous pouvez annuler un nouveau contrat pendant une période d'essai (généralement 15 jours, plus longue pour les clients handicapés) sans frais, si l'utilisation reste dans les limites prévues.
